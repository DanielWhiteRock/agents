# What this pack is made of

Three bodies of work, used under MIT, unmodified except where noted.

| Skill | From | Author |
|---|---|---|
| `ponytail` | [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) | Dietrich Gebert |
| `thermo-nuclear-code-quality-review` | [cursor/plugins](https://github.com/cursor/plugins/tree/main/cursor-team-kit) · cursor-team-kit | Cursor |
| `architect`, `how`, `why`, `interrogate`, `blast-radius`, `tdd`, `correct`, `show-me-your-work`, `engineering-principles` | [cursor/plugins](https://github.com/cursor/plugins/tree/main/pstack) · pstack | Poteto |

pstack ships 58 skills. This pack carries eleven of them, plus its 24
principles folded into one indexed skill rather than 24 separate ones — a
skill's description occupies the context window for the whole session, so the
cost of carrying a skill is paid on every turn whether or not it is used. The
ones left out are either narrower than this pack (`ketchup-video`,
`make-bot-ui`), specific to one stack (`typescript-best-practices`), or about
operating an agent fleet rather than engineering (`swarm`, `arena`,
`setup-pstack`).

The composition is ours; the skills are theirs.
